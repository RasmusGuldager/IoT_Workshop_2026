# IoT Workshop

I denne workshop skal du skrive kode til en lille computer, der hedder en **ESP32**. Den er ikke større end en tommelfingernegl og kan forbinde til WiFi. Til sidst kan din ESP32 sende beskeder til en skærm i lokalet og til de andre deltageres ESP32'ere.

## Sådan kommer du i gang

1. Klik på den grønne knap **Code** øverst på denne side, og vælg **Download ZIP**.
2. Find filen i din mappe med overførsler, og pak den ud. På Windows: højreklik og vælg **Udpak alle**. På Mac: dobbeltklik på filen.
3. Åbn mappen **del1**, og åbn filen **Opgaver.md**. Følg vejledningen der.

## Workshoppens dele

Lav delene i rækkefølge. Det er helt i orden ikke at nå dem alle.

| Del | Indhold |
|---|---|
| [Del 1](del1/Opgaver.md) | Installér programmet, og få din ESP32 til at blinke |
| [Del 2](del2/Opgaver.md) | Styr lyset og knappen på din ESP32 |
| [Del 3](del3/Opgaver.md) | Forbind til vores server, og send beskeder til skærmen |
| [Del 4](del4/Opgaver.md) | Send beskeder til din makker |
| [Del 5](del5/Opgaver.md) | Ekstra: Lav din egen hjemmeside |

## Hver del har tre filer

| Fil | Hvornår bruger du den? |
|---|---|
| **Opgaver.md** | Start her. Her står, hvad du skal lave. |
| **Hints.md** | Hvis du ikke kan komme videre. Her står, hvilken kode du kan bruge. |
| **Løsninger.md** | Hvis du stadig ikke kan komme videre. Her står den færdige løsning. |

Alle filerne findes også som PDF med samme navn, for eksempel **Opgaver.pdf**. Brug dem, hvis .md-filerne ser mærkelige ud på din computer.

Du er altid velkommen til at spørge os.
